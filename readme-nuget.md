A .NET library for building query specifications.

The usage guide and the documentation are in the repository's [docs folder](https://github.com/bandoyer/OpenSpecification/tree/main/docs).

[CHANGELOG.md](https://github.com/bandoyer/OpenSpecification/blob/main/CHANGELOG.md) lists each version's changes and breaking changes, and how to move a project to 10.0.0.
